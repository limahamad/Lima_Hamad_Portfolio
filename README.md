# Lima Hamad Modern Portfolio

This version uses the modern dark portfolio design while incorporating the content shown in the supplied Squarespace screenshots.

## Open locally
Extract the ZIP and double-click `index.html`.

## Add assets
Place your files in the `assets` folders using these names:

- `assets/images/profile.jpg`
- `assets/images/florabot.jpg`
- `assets/images/deepfake.jpg`
- `assets/images/hail-the-potato.jpg`
- `assets/images/just-firefighter.jpg`
- `assets/images/sci-orbit.jpg`
- `assets/images/scooby-dooby-doo.jpg`

Optional:
- `assets/videos/florabot.mp4`
- `assets/documents/Lima-Hamad-CV.pdf`

## Update before publishing
Replace:
- `your.email@example.com`
- LinkedIn and GitHub placeholder links (`href="#"`)
- Publication link if available

## Deploy to Vercel
1. Extract the ZIP.
2. Upload the folder to GitHub, or deploy it directly as a static project.
3. Import the project into Vercel.
4. Framework preset: Other.
5. No build command is required.
